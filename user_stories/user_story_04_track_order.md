# User Story Title: Track Order Status

## Priority: Medium (Iteration-2 core feature)

Users can track the status of their food orders after placing them.

## Estimation: 2 days

Planning Poker:
- BS: 2 days

## Assumptions:
- Order has already been placed
- Backend returns order status

## Description:

Description-v1:
The system displays the current status of an order:
- Pending
- Preparing
- Out for delivery
- Delivered
