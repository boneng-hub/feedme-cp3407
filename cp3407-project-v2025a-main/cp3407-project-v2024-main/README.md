# Project planning BEFORE iteration-1, (see chapters 1-3)
The project is FeedMe, a modern food delivery web application inspired by FoodPanda.
The system allows customers to browse restaurants, place food orders, and track order status.
Restaurants can manage menus and receive orders.

Planned technology stack:
- Frontend: React.js
- Backend: Node.js (Express)
- Database: MySQL
- Cloud: AWS (EC2, RDS)
- 
* User Registration and Login, priority High, 2 days
* Browse Restaurants, priority High, 2 days
* View Restaurant Menu, priority High, 1 day
* Place Food Order, priority High, 3 days
* Track Order Status, priority Medium, 2 days
* Restaurant Menu Management, priority Medium, 2 days
* Rate Restaurants, priority Low, 1 day


Total: 13 days
